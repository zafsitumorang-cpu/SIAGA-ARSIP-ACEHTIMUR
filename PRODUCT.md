# SIAGA ARSIP

Aplikasi kearsipan Bawaslu Kabupaten Aceh Timur untuk mencatat surat masuk/keluar, mengunggah berkas, dan mengelola disposisi berdasarkan peran serta subbagian. Publik melihat angka agregat dan filter tahun. Staf masuk memakai akun pengelola. Data saat ini adalah data uji coba.

Landing page membantu publik memahami layanan dan melihat statistik, serta mengarahkan staf ke login. Jangan menampilkan rincian dokumen, angka contoh sebagai data nyata, atau klaim penyimpanan/enkripsi/sertifikasi yang belum diverifikasi. Implementasi saat ini menggunakan Node.js dengan frontend vanilla; antarmuka harus berfungsi pada ponsel dan desktop.
